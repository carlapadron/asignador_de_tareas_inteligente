# Asignador Inteligente de Tareas para Proyectos.

Sistema web que asigna tareas para un proyecto dependiendo de las habilidades de los empleados con Inteligencia Artificial y cálculo de compatibilidad de personal en tiempo real.

## Características Principales

- **Copiloto con Inteligencia Artificial:** Desglosa requerimientos en lenguaje natural y extrae habilidades técnicas automáticamente.
- **Matcher de Personal:** Calcula el porcentaje (%) de compatibilidad entre los empleados y la tarea a realizar.
- **Inicios de Sesión:** Accesos independientes para el Administrador y los Empleados.
- **Diseño Moderno:** Interfaz responsiva en modo oscuro con efectos visuales.
- **Persistencia:** Guarda las tareas y cambios localmente en el navegador.

## Tecnologías Usadas

- React 19
- Tailwind CSS v4
- Vite
- JavaScript (ES6+)
- LocalStorage Web API
